# Vue 示例

`@starweave-lab/vite-plugin-loading` 的 Vue 3 Composition API 示例。

```bash
pnpm --filter vite-plugin-loading-example-vue dev
```

示例展示了 `type`、`classPrefix`、CSS 变量形式的动态 `themeColor`、`maskBackground`、`title` 以及 `hideAppLoading()`。页面会渲染全部 8 种内置动画，并提供真实遮罩的重放按钮。

浅色、深色和跟随系统模式会同时更新应用与由主题色生成的 loading 渐变。
